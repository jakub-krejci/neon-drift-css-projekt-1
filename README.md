# Neon Drift – pracovní list CSS

Interaktivní pracovní list pro seminář z informatiky. Žáci nastylují fan page fiktivní hry Neon Drift.

- `index.html` – pracovní list
- `img/` – obrázky pro pracovní list
- `neon-drift-zadani.zip` – zadání pro žáky (HTML, prázdný style.css, obrázky), ke stažení přímo z pracovního listu
